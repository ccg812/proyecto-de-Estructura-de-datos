Conceptos Fundamentales de Estructuras de Datos

Las estructuras de datos son la base de la informática. Aprende cómo organizar la información de manera eficiente.

1. Arrays (Arreglos)

Una colección de elementos (normalmente del mismo tipo) almacenados en posiciones de memoria contiguas. Se accede a ellos mediante un índice.

El acceso es de tiempo constante (O(1)) porque la dirección de cualquier elemento puede calcularse directamente a partir de la dirección base y el índice.

Ejemplo (Python/JavaScript):


// Array de 5 elementos
numeros = [10, 20, 30, 40, 50]
// El elemento '30' está en el índice 2
primerElemento = numeros[0]

2. Listas Enlazadas (Linked Lists)

Una colección lineal de elementos (llamados nodos) donde cada nodo apunta al siguiente. No requiere memoria contigua.

Ventaja: La inserción y eliminación son muy eficientes, ya que solo hay que reajustar los punteros, no mover todos los elementos.

Ejemplo de un Nodo:


// Un Nodo tiene un valor y una referencia al siguiente
class Nodo {
    constructor(valor) {
        this.valor = valor;
        this.siguiente = null; // Puntero al próximo nodo
    }
}

3. Pilas (Stacks) y Colas (Queues)

Son estructuras lineales con restricciones en cómo se accede a los datos:

  • Pila (Stack): Funciona con el principio "LIFO" (Last In, First Out - Último en Entrar, Primero en Salir). Como una pila de platos.
  • Cola (Queue): Funciona con el principio "FIFO" (First In, First Out - Primero en Entrar, Primero en Salir). Como la fila de un supermercado.

Analogía Interactiva: ¿Cuál es el último elemento que sale de una "Pila" si insertamos: A, B, C?

Respuesta: ¡C! (Último en entrar, primero en salir).

4. Iteradores y Variables Indexadas

Un iterador es una herramienta que permite recorrer una estructura de datos elemento por elemento, sin necesidad de conocer su implementación interna. Una variable indexada es aquella que accede a elementos mediante un índice, como en los arreglos.

Los iteradores permiten recorrer listas, arreglos o colecciones de forma ordenada y segura. Son esenciales para aplicar operaciones como búsqueda, filtrado o transformación de datos.

Ejemplo (Python):


# Usando un iterador implícito con 'for'
numeros = [10, 20, 30, 40, 50]
for numero in numeros:
    print(numero)  # Imprime cada elemento

# Usando índice (variable indexada)
for i in range(len(numeros)):
    print(f"Índice {i}: {numeros[i]}")
