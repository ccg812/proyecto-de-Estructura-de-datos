Arrays (Arreglos): La Base de las Estructuras de Datos

1. ¿Qué es un Array (Arreglo)?

Un "Array" es una colección de elementos (generalmente del mismo tipo) almacenados en "posiciones de memoria contiguas" (juntas).

Es la estructura de datos más básica y utilizada. Piensa en un array como una fila de casilleros numerados, donde cada casillero guarda un valor.

  • Homogéneo: En muchos lenguajes (como Java o C++), todos los elementos deben ser del mismo tipo (ej: todos números enteros).
  • Tamaño Fijo: En la mayoría de implementaciones, el tamaño del array se define al crearlo y no puede cambiar.

Ilustración Clave: Cada elemento se accede mediante su "índice", que siempre empieza en "0".

2. Características Fundamentales y Eficiencia

Acceso Rápido (Acceso Directo)

La característica más poderosa. Podemos acceder a cualquier elemento del array directamente y en tiempo constante, lo que se conoce como complejidad O(1).

Ventajas:

  • Velocidad de Lectura: Acceder a un elemento por índice es instantáneo.
  • Simpleza: Son sencillos de implementar y entender.

Desventajas:

  • Inserción/Eliminación Lenta: Si insertas o eliminas un elemento en medio, todos los demás deben moverse para mantener la contigüidad, lo que puede ser lento (O(n)).
  • Tamaño Fijo: Redimensionar un array (crear uno nuevo y copiar los datos) es costoso.

3. Operaciones Típicas y Ejemplos de Código

A. Acceso (Lectura)

Obtener el valor de un elemento específico usando su índice.


// Python
nombres = ["Ana", "Beto", "Carlos"]
# Acceder al elemento en el índice 1 (el segundo elemento)
print(nombres[1]) # Salida: Beto

B. Inserción al Final

Agregar un elemento nuevo al final de la colección (solo si hay espacio, o en el caso de listas dinámicas).


// Java (simplificado)
int[] edades = new int[4]; // Array de 4 espacios
edades[0] = 25;
edades[1] = 30; 
// Insertar al final
edades[2] = 45;

C. Inserción/Eliminación en Medio

4. Arrays Multidimensionales (Matrices)

Un array puede contener otros arrays. El más común es el array de dos dimensiones, conocido como "matriz", que representa una tabla o cuadrícula (filas y columnas).

Ejemplo (Tabla de Datos):


// Python: matriz 2x3
matriz = [
  [1, 2, 3],  // Fila 0
  [4, 5, 6]   // Fila 1
]
# Acceder al elemento en la Fila 1, Columna 0 (el valor 4)
print(matriz[1][0]) # Salida: 4
